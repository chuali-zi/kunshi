> 本文是逐件资产的**制作执行规格**,面向 AI 辅助建模(Blender MCP)工作流。

## 1. 全局硬规范(每件资产必须满足)

### 1.1 单位、坐标与朝向

| 项 | 规定 |
|---|---|
| 单位 | 1 Blender Unit = 1 米,建模按真实尺寸,导出前 Apply All Transforms,Scale 必须为 `(1,1,1)` |
| Blender 坐标 | Z 轴向上,物体"正面"朝 `-Y` |
| FBX 导出 | `Forward = -Z`,`Up = Y`,勾选 Apply Unit / Use Space Transform |
| 游戏方位 | Unity 场景中:北墙 = `+Z`,东墙 = `+X`,南墙(电视/相机)= `-Z`。规格卡中"朝南"即物体正面在 Unity 中朝 `-Z` |

### 1.2 原点(Pivot)三原则

1. **落地静物**:原点在包围盒底面中心(落地点),Y=0 即贴地。
2. **旋转件**:原点在真实转轴上——门板在铰链轴、抽屉在滑轨后端中心、钟针在轴心、灯开关在旋钮轴。
3. **手持物**:原点在握持点——球棍在双手握区中部、手电在握筒中心、手枪在握把与扳机护圈交界。

### 1.3 拆件规则

- 凡是玩法上**可独立交互 / 独立破坏 / 独立掉落**的部分,必须是独立 Object(独立网格 + 独立原点),不允许只在贴图或同网格上做外观切分。
- 状态变体(`_Intact` / `_Damaged` / `_Broken`)是**同尺寸、同原点**的整件替换网格,切换时不允许出现明显体积跳变。
- 每个 FBX 内的层级树、对象命名在规格卡里给出,**照抄,不要自创**。

### 1.4 面数预算(三档,均指三角面)

| 档 | 预算 | 适用 |
|---|---|---|
| S | ≤ 1,500 | 小道具:遥控器、书、花瓶、手电、挂钟、杂物 |
| M | ≤ 4,000 | 中型:木椅、台灯、吊灯、球棍(远低于上限即可)、镜子、枪、地毯、被子单形态 |
| L | ≤ 8,000 | 大型/近景:房间壳、扶手椅、床、书柜、抽屉柜、CRT 电视(单状态) |

- 碎件包(`_Broken` 的散落件)整包 ≤ 2,000。
- 固定机位单房间,预算允许上浮 20%,但必须先用完轮廓再花在倒角上;**看不见的底面/背面/内腔一律删面**(贴墙家具背板保留大面即可)。
- 本作不做 LOD,不做光照烘焙 UV2。

### 1.5 UV 与贴图

- 每件资产一套 UV0,无重叠(镜像复用允许,但破坏态受击面不镜像)。
- Texel Density 目标:墙/地/顶 **256 px/m**;普通家具道具 **512 px/m**;近景关键件(CRT 电视、门、扶手椅、镜框)**768~1024 px/m**。
- 贴图上限 2K;小道具并入共享 Atlas(见 §6);只有电视允许 4K(它离相机最近)。
- 贴图命名:`TEX_<材质名>_BC`(Albedo,sRGB)/ `_N`(法线,Linear)/ `_MRA`(R=Metallic, G=Roughness, B=AO,Linear)。PNG 无损交付。

### 1.6 材质

- 目标管线 **URP Lit**,每件资产材质槽 ≤ 2(规格卡中注明槽位名),共享材质见 §6 材质组。例外(2026-07-17 B08 定夺):吊灯罩内外分色需要,`PRP_CeilingLamp` 两态允许第 3 槽 `MAT_LampShade_Inner`(浅色暖灰反光面),Unity 侧不合并。
- 不在模型里烘焙任何光照、阴影、屏幕内容;发光件(电视屏、灯泡)只留独立材质槽,发光由 Unity 侧材质接管。

### 1.7 碰撞

- 模型**不交付碰撞网格**;Unity 侧用 Box/Capsule/Convex 近似(灰盒已有)。因此外形要"碰撞友好":主体轮廓接近盒/柱,不要有细长悬空须状结构。
- 例外:碎件包每块必须是**闭合凸包形状**(直接作 Convex MeshCollider)。

### 1.8 空物体挂点(Empty/Socket)

- 需要 Unity 挂接的位置在 FBX 里放空物体,命名 `SOCKET_<用途>`,轴向与 §1.1 一致。各资产需要哪些 SOCKET 在规格卡里列出。
- 场景逻辑锚点(HideAnchor、PlacementSocket、Zone 触发器)由 Unity 场景负责,模型**不要**包含,但模型必须给它们留出规格卡标注的净空。

### 1.9 交付与验收流程

1. 源文件:`art/source/blender/<类别>/<资产ID>_v001.blend`,大改递增版本。
2. 导出:`art/exports/<类别>/<资产ID>.fbx` + 贴图到同目录 `textures/`。
3. 自检清单(全部通过才算"待验收"):
   - [ ] 真实尺寸与规格卡一致(±5% 内)
   - [ ] 原点、朝向符合 §1.2 / §1.1
   - [ ] 拆件与命名树和规格卡一致
   - [ ] 三角面数在预算内;法线无翻面;无重叠废面
   - [ ] UV 无非故意重叠,Texel Density 达标
   - [ ] 状态变体同原点同占位,切换无跳变
4. 终验:导入 Unity 后**在固定机位下截图对比**(相机参数见 §2),检查轮廓、遮挡、与邻接家具的空间关系;转台好看不算过。

## 2. 场景基准(一切尺寸与构图的锚)

- 房间内净尺寸:**6.2m(东西) × 5.2m(南北) × 2.8m(高)**。
- 固定相机(= CRT 电视屏幕位置):位置 `(0, 1.15, -2.14)`,朝向房间中央偏上(注视点约 `(0, 1.0, 0.4)`),FOV 62°,near clip 0.03。**所有资产的最终验收视角就是这台相机。**
- 门洞:东墙偏北,洞口 `0.9 × 2.05m`,门轴在洞口北侧(Unity 坐标约 `x=3.05, z=1.0`),门板向房内(西北方向)开。
- 中央表演净空:地毯前景保留 `2.2 × 2.4m` 无障碍区(神秘人入场、闪避、双人搏斗用),任何家具摆位不得侵入。
- 布局全图与关键空间关系(门后盲区、床底藏点、镜面反射角)以 [items_interactions.md](../../docs/items_interactions.md) §一 为准。

## 4. 场景结构规格卡(ENV)

### ENV_RoomShell — 房间壳 · P0 · 预算 L

- **尺寸**:内净 `6.2 × 5.2 × 2.8m`;墙厚 ≥ 0.1m(单面片不接受,踢脚线要有实体厚度感)。
- **拆件命名树**:
  ```
  ENV_RoomShell
  ├─ Shell_Floor
  ├─ Shell_Ceiling
  ├─ Shell_Wall_N / Shell_Wall_S / Shell_Wall_W
  ├─ Shell_Wall_E          (含门洞开口 0.9×2.05,位置见 §2)
  └─ Shell_Skirting        (四周踢脚线,可与墙合并材质)
  ```
- **原点**:整组原点在地面中心 `(0,0,0)`,各子件保持世界位置归组。
- **开口**:东墙门洞(§2);北墙窗洞 `1.4 × 1.1m`、窗台底边高约 0.9m、位于北墙偏西(书柜与木椅之间,中心约 Unity `x=-1.2`),窗洞由 `ENV_BoardedWindow` 填充。
- **材质槽**:`MAT_Wallpaper_FloralAged`(四墙)、`MAT_Floor_DarkGreen`(地)、天花可复用墙纸材质刷白变体。
- **要点**:墙面 UV 平直无扭曲(要接受命中 Decal);碎花墙纸可平铺不留明显重复热点;地面暗绿低绒、低频纹理(固定机位下高频会闪)。
- **验收**:固定机位下四角自然压暗后仍读得出墙/地分界;门洞、窗洞位置与 §2 一致。

### ENV_DoorSet — 门组 · P0 · 预算 M

- **尺寸**:门板 `0.9 × 2.05 × 0.04m`;门框贴合门洞;把手高 1.0m。
- **拆件命名树**:
  ```
  ENV_DoorSet
  ├─ Door_Frame            (原点同房间壳)
  ├─ Door_Panel            (原点在铰链轴线底端,轴=竖直)
  │   └─ SOCKET_Handle
  └─ Door_Handle           (深色旧金属把手,独立件,原点在转轴)
  ```
- **状态**:门板只需完好一态;"被踹开"是运动不是破坏,无需碎门板。
- **材质槽**:`MAT_Wood_Worn`(门板/框)+ `MAT_Metal_Dark`(把手)。
- **要点**:旧白/浅色木门(构图上是东墙的亮色块);把手在门板西侧(朝房内);门板内侧下沿留平整区(椅背顶门的接触位,高度 0.9~1.0m 处不要有装饰凸起)。
- **验收**:以铰链为轴旋转 0°~110° 无穿框;把手侧对固定机位轮廓清楚。

### ENV_BlackCorridor — 门外黑走廊 · P0 · 预算 S

- **尺寸**:约 `1.2m 宽 × 3m 深 × 2.6m 高`,接在门洞外。
- **拆件**:`Corridor_Shell` 单件(墙地顶一体即可)。
- **材质槽**:单槽近黑哑光;尽头无门无窗,吞光。
- **要点**:只在开门瞬间被看到,面数越省越好;不做任何可辨认细节(留白原则)。

### ENV_BoardedWindow — 封死窗 · P1 · 预算 M

- **尺寸**:整体 `1.4 × 1.1m`,嵌入北墙窗洞;远看像一幅深色挂画(设计要求:第一眼读成"画",走近才辨认出是封窗)。
- **拆件命名树**:
  ```
  ENV_BoardedWindow
  ├─ Window_Frame          (深色厚重外框,画框感)
  ├─ Window_Board_01 … 05  (4~5 条横向木板,每条独立,原点各自中心)
  ├─ Window_Board_Broken_01 … (对应每条木板的断裂替换件,两三段/条)
  └─ Window_BrickWall      (木板后 0.1m 的完整砖墙面)
  ```
- **状态**:每条木板 `_Intact` → 断裂替换;全部打碎后露出砖墙(D15)。
- **材质槽**:`MAT_Wood_Worn`(框/板)+ 砖墙复用墙体材质的砖变体。
- **要点**:木板缝隙**不透光**;板面色调压深,与墙纸拉开成"画"的错觉。
- **验收**:固定机位下读作深色矩形挂画;逐条敲碎的替换件与原板同占位。

### ENV_WallDamageKit — 墙面破损件 · P1 · 预算 S

- **交付**:三档墙皮剥落 Decal 用法线/Albedo 贴图(平面),外加 3~5 块微凸墙皮碎屑网格(每块 ≤ 50 面)。
- **要点**:凹坑视觉主体由 Unity Decal 完成,本资产只补"边缘翘皮"的立体感;不制作可打穿墙体。

## 5. 家具规格卡(FUR)

### FUR_Armchair — 高背扶手椅(逻辑名"沙发") · P0 · 预算 L

- **尺寸**:`0.95 宽 × 0.95 深 × 1.15m 高`;**椅背上沿高 1.1~1.2m**(硬性:必须完全遮住蹲姿角色、露出站姿头肩,这是 D03 成立条件)。
- **摆位朝向**:高书柜东侧留 ≈0.5m 通行空隙、不靠北墙(椅背↔北墙 ≈0.7m 蹲行通道,与书柜/北墙围出可绕行 L 形区,即 D03 绕后躲藏与 D03′ 绕后查看动线),座面朝南偏东微侧约 20°(不正对南墙,微微侧向门;正面朝 `-Y` 建模)。
- **拆件命名树**:
  ```
  FUR_Armchair
  ├─ Armchair_Body         (原点=落地中心)
  └─ Armchair_Cushion      (坐垫独立,可被"掀一下",原点在垫底中心)
  ```
- **材质槽**:`MAT_Leather_Burgundy` 单槽;磨损集中在扶手前端与坐面。
- **净空要求**:椅背后方保留 `1.0 × 0.7m` 蹲伏净空(Unity 侧 HideAnchor/Zone 在此)。
- **验收**:固定机位偏左前景处轮廓厚重;蹲姿胶囊(高 1.0m)藏于背后不露头。

### FUR_Bed — 单人床 · P0 · 预算 L

- **尺寸**:`2.0 长 × 1.0 宽`;**床底净空 0.4m**(硬性:容纳俯卧角色 + 拖拽路径);床面高约 0.6m;床头板靠东。
- **摆位**:贴北墙、木椅右侧,床侧面朝向固定机位。
- **拆件命名树**:
  ```
  FUR_Bed
  ├─ Bed_Frame             (木床架含四腿+床头板)
  ├─ Bed_Mattress          (床垫独立)
  └─ Bed_Pillow            (枕头独立)
  ```
- **材质槽**:`MAT_Wood_Walnut`(架)+ `MAT_Fabric_Bedding`(垫/枕)。
- **要点**:床底四腿之间无横撑挡拖拽;床垫上表面平整(被子拿走后要能读出"空印",由贴图微差或 Decal 实现)。
- **验收**:床底塞入 `1.8 × 0.5 × 0.35m` 盒体不穿帮;固定机位能看清床沿下的阴影缝。

### FUR_WoodChair — 直背木椅(苏醒点) · P0 · 预算 M

- **尺寸**:座面 `0.45 × 0.5m`、座高 0.45m、背高 0.95m。
- **摆位**:贴北墙正中、正对南墙相机,座面朝南——它是画面绝对中心,轮廓必须"看着就能抡"。
- **拆件命名树**:
  ```
  FUR_WoodChair            (完好态,原点=落地中心)
  FUR_WoodChair_Broken     (散架碎件组:椅腿×2、座板、背板,共 ≤4 块)
  ```
- **状态**:完好 / 散架(顶门被踹飞、抡砸损坏后)。
- **材质槽**:`MAT_Wood_Worn` 单槽(浅色旧木,和深色胡桃木家具拉开)。
- **交互对齐**:椅背上横杆直径 ≤ 0.05m 且离背板有指缝空隙(视觉上"卡得进门把手下");双手搬运位在座面两侧。
- **验收**:固定机位下与背后墙纸对比清晰;散架件与完好态同占位切换无跳变。

### FUR_Bookcase — 高书柜 · P0 · 预算 L

- **尺寸**:`1.0 宽 × 0.35 深 × 2.1m 高`,五层。
- **摆位**:贴西墙北段,固定机位最左侧的深色边框。
- **拆件命名树**:
  ```
  FUR_Bookcase
  ├─ Bookcase_Body         (柜体一体,原点=落地中心)
  ├─ SOCKET_Bat            (顶层球棍斜靠位)
  └─ SOCKET_Shelf_01 … 05  (各层书本摆放锚点)
  ```
- **状态**:只一态;"推倒"是刚体运动,倒地后柜体侧面成为半高掩体(侧板要平整可靠地)。
- **材质槽**:`MAT_Wood_Walnut` 单槽。
- **要点**:书与球棍**不建在柜体网格里**,全部经 SOCKET 摆放独立道具;层板间净高 ≥ 0.32m(容得下书本道具)。
- **验收**:推倒后(旋转 85°)无尖角戳穿地面;倒地侧面能遮蹲姿。

### FUR_Dresser — 三屉抽屉柜 · P1 · 预算 L

- **尺寸**:`1.1 宽 × 0.48 深 × 0.85m 高`。
- **摆位**:贴西墙、书柜南侧;台面放台灯与遥控器。
- **拆件命名树**:
