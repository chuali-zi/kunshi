# 《困室》美术资产台账

## 1. 美术方向

- 场景：约 `6.2m × 5.2m × 2.8m` 的封闭复古卧室，像被固定机位观看的旧舞台布景。
- 色彩：米黄旧碎花墙纸、暗绿地面、胡桃木家具、深酒红皮革扶手椅、暖白床品。
- 光照：顶灯形成中央硬光，西侧台灯提供低位暖光，四角明显压暗。
- 气质：写实比例、适度风格化细节、旧而非废墟；不做满屋垃圾和重度末日破损。
- 构图优先级：固定机位中先读到人物、门、扶手椅、床、书柜和电视关系，再读到小道具。

## 2. 优先级定义

- `P0`：垂直切片必需；先完成尺寸和轮廓，材质可暂时简化。
- `P1`：完整玩法必需；支撑剩余交互、黑暗路线和结局。
- `P2`：氛围与留白；不阻塞可玩版本。

## 8. 不应交给 Blender 制作的内容

- CRT 扫描线、雪花、闪帧、全屏裂纹和暗角：Unity Shader/Post Process。
- 镜中实时画面、电视 RenderTexture：Unity 相机与材质。
- 手电体积光锥、环境光五档变化：Unity 灯光/VFX。
- 墙面命中凹坑、血迹、拖痕：Unity Decal；Blender 只做少量通用碎片。
- 枪口火光、灯泡爆裂粒子、玻璃飞散：Unity VFX/粒子系统。
- 门、抽屉、钟针的简单转动：Unity Transform/Timeline，不烘焙骨骼动画。
- 大部分死亡倒地后的最终姿态：Unity Ragdoll，不逐条制作死亡动画。

## 9. Blender MCP 推荐创建批次

每次只生成一个语义清晰的批次，生成后先核对比例和拆件，再进入下一批。

| 批次 | 内容 | 完成标准 |
|---|---|---|
| B01 房间白模 | `ENV_RoomShell`、`ENV_DoorSet`、`ENV_BlackCorridor` | 固定机位、门后盲区和中央 `2.2 × 2.4m` 表演净空成立 |
| B02 核心构图家具 | 扶手椅、床、木椅、书柜、电视柜 | 人物遮挡、床底净空、电视屏幕高度成立 |
| B03 核心交互物 | 被子 4 态、球棍、CRT 3 态、两盏灯 | 可拾取部件原点正确，状态可直接替换 |
| B04 次级家具 | 抽屉柜、圆几、地毯、封死窗 | 抽屉/木板独立，顶门与绊倒碰撞空间成立 |
| B05 小道具 | 遥控器、书、花瓶、挂钟、镜子、杂物 | 共享材质，固定机位仍可辨认关键轮廓 |
| B06 角色与装备 | 玩家白模、神秘人、风衣、双枪、手电 | 共用 Humanoid 规范，握持点和枪套位置通过测试 |
| B07 破坏件 | 椅子、灯、窗板、电视、花瓶、镜子碎件 | 碎件数量受控、碰撞简单、状态切换无明显体积跳变 |
| B08 材质打磨 | 全部 P0/P1 材质 | 先在 Unity 固定机位和两档光照下验收，再做局部细化 |

## 10. 首轮制作范围

为避免一次性制作过量，首轮只做：B01、B02、`CH_Player`/`CH_Killer` 灰模、球棍、门、顶灯和主手枪灰模。它足够验证固定机位、D01、D03、D07 与循环重置；尺寸未验收前不要开始 D08 搏斗、小道具和精细贴图。
