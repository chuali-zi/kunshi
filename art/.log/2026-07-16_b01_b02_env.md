# 2026-07-16 B01 房间白模 + B02 核心家具制作记录

执行方式：Blender 5.1.2 headless（`art/source/blender/environment/build_*.py`）。

## ★ 重要发现：Blender→Unity 轴向实证（axisprobe）

用标记物 FBX 在 Unity 6000.4.6f1 批量模式实测（探针脚本已删，结果保留在此）：

```
Blender (x, y, z)  →  Unity (-x, z, -y)
```

- Unity **东(+X)** = Blender **-X**；Unity **北(+Z)** = Blender **-Y**；上 = +Z（不变）。
- 影响：所有含"绝对房间位置"的资产（房壳门/窗洞、门组、走廊）按此映射建模；
  家具/道具在 Unity 场景里摆位，模型内部不对称件（床头板、椅背）由场景旋转消化。
- 首版房壳按错误假设（Blender +X=东）建过一次，已按实证映射重建；spec §1.1 的
  "FBX Forward=-Z/Up=Y"导出参数不变，Unity 侧 X 翻转是 Unity FBX 导入器的固有行为。
- 合成预览摆位公式：`Blender = (-Unity_x, -Unity_z, Unity_y)`。
