# 2026-09-26 第二轮：坐姿、手电拉扯与抢枪收尾

这一轮继续推进可玩链和动作反馈，没有把程序修复等同于 MV 表现已经还原。使用了项目内 `Art/reference/character/CH_player/正面_正坐在凳子上.jpg` 核对开场木椅姿态；尚未完成完整 MV 的逐帧复核。

## 已落地的改变

- 开场和循环复位使用已有 `POSE_Player_SitChair`。苏醒计时结束、没有玩家输入时仍保持坐姿；第一次有效输入立即回到椅前净空站点并继续原操作，视觉用 0.25 秒过渡。坐椅时关闭角色移动碰撞，防止椅子把角色挤开。E3 已有的坐姿事实也接入表现层。
- D21 首次拾取手电进入三个 1 秒的黑暗拉扯 QTE 窗口。脱身时手电被打落，随后开放真实拾取窗口；玩家重新拾取后可以直照神秘人，或走镜面分支。拾取主枪仍进入 D22。避免照光后才倒放拉扯，也没有在脱身后自动把手电送回手中。
- D21 分阶段使用倒地、拉扯、脱身、挡光、备用枪动作；掉落选择时神秘人保持落地姿态，玩家可以行动。拉被的人在神秘人摔倒时不会同时被强制播放摔倒动画。
- D22 的首枪、闪避、空仓/超时和终结演出接成连续流程。终结演出持续约 2 秒，0.7 秒把备用枪挂入手中，1.3 秒产生枪击音画，2 秒完成原死亡结算。掉落备用枪不再提前出现在房间内固定坐标。
- 正式房间新增了枪口闪光池和明确的枪口节点。D21、D22 的备用枪开火都保留手中的枪，并避免结算阶段再重复播放一次枪声和举枪动作。
- 实机检查后补做备用枪的握点和瞄准校准，消除枪身埋入手掌、枪口朝偏；换挂到世界缩放 206 的导入手骨时保留武器世界尺寸，回枪套恢复原局部变换。枪口粒子改为短促尖芒，消除无透明纹理的方块。开场站点向左避开床的碰撞边缘，避免刚起身被角色控制器推开。

## 导入时间错误

旧 `art/pipeline/add_animation_events.py` 把绝对秒数直接写进 `ModelImporter` 的归一化事件字段。实际 Unity 测量显示，D21 动画从约 7.96 秒被撑成 57.3 秒，末尾是长时间保持的姿势；倒地、挡光和拔备用枪也被拉长。

修复通过 Editor API 更新受影响的 16 个动画导入器，并把旧 Python 入口改为调用 Editor 修复方法，避免再次手写错误的 `.meta`。保留已经有效的 0–1 事件时间，重复运行不会再次除以时长。Unity 的 [AnimationClipInfoProperties 实现](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Editor/Mono/ImportSettings/AnimationClipInfoProperties.cs) 可用于核对导入事件与剪辑事件之间的时间转换；具体修复结论以本项目导入前后测量为准。

| 片段 | 修复前 Unity 长度 | 修复后 Unity 长度 |
| --- | ---: | ---: |
| PAIR_D21 两侧 | 57.30 秒 | 7.96 秒 |
| AN_Killer_Fall | 7.99 秒 | 2.96 秒 |
| AN_Killer_BlockLight | 7.99 秒 | 2.96 秒 |
| AN_Killer_DrawBackupFire | 9.90 秒 | 3.96 秒 |

阶段片段仍来自当前已有动画，导入正确不代表人物接触、手型和动作质量已经达到 MV 水准。双人拉扯的空间接触和不同角度下的姿势还需要视觉检查。
