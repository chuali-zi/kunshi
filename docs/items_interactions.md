## 一、房间布局

约 6.2m × 5.2m 的复古卧室。电视机嵌在南墙中央，屏幕位置就是固定镜头；全屋唯一出入口在东墙偏北。构图对齐参考概念图：宽角正面舞台式取景，家具沿北墙一字排开，木椅（苏醒点）贴北墙居中正对镜头，深绿地毯留出大片前景净空。

**关键空间关系（影响死法成立）：**
- **主表演区**：木椅（苏醒点）、床与房门构成横向三点；前景深绿地毯至少留出 2.2m × 2.4m 净空，保证神秘人入场、投掷闪避和双人搏斗不穿模。
- **门后盲区**：房门朝北侧向内打开，完全打开后门板遮住东北角三角区；该区域既不在电视固定镜头内，也不在神秘人入门后的第一眼扫描弧中 → D08 偷袭点。
- **扶手椅遮挡**：深酒红绒面高背扶手椅（参考图翼背款）；紧贴高书柜右侧、比木椅略靠南（镜头里偏左靠前），座位朝南偏中。宽靠背仍能遮住蹲姿，站立会露出头肩（D03）。
- **木椅苏醒点**：直背木椅贴北墙正中、正对南墙固定机位（CRT=镜头），座位朝南；主角每次循环在此坐姿苏醒。搬离后中央区域完全打开。
- **镜面引导**：半身镜在东墙南段并向房内偏转约 12°，镜中可同时收进房门和南墙电视 → 玩家能在镜子里“看见镜头自己”。
- **床底藏点**：单人床贴北墙、木椅右侧；床头偏东，床底 40cm 净空。床右侧（靠门）放小圆几+白瓷花瓶，迫使绕床尾或跨地毯接近门口。
- **陷阱动线**：长条地毯从扶手椅前脚斜铺到门内侧，既是神秘人的自然入场线，也是玩家可在远端拉拽的 D16 机关；门口最后 1m 保持可铺被子的空地。

**美术落地建议（对齐参考概念图）：** 米白底小粉红玫瑰碎花墙纸、深绿满铺地毯、胡桃木家具、深酒红绒面高背椅、暖白略皱床品、黑罩吊灯中央硬光。封死窗做成深色画框挂画（远看像超现实几何画，近看才是木板封窗）；挂钟停在固定时刻；东墙白门深色把手；圆几上白瓷瓶插红玫瑰。四角允许明显压暗，左侧书柜落入半影。

## 二、物品详细设计

统一动词集见 [game_outline.md](game_outline.md) §3.2：检查 / 拾取 / 使用 / 投掷 / 挥击 / 搬运 / 躲藏 / 放置。

每件物品条目格式：**位置与外观 → 支持动词 → 交互细节 → 组合交互 → 关联死法 → Unity 要点 → 拓展钩子**。

---

### 1. 沙发（高背扶手椅 / 掩体）
- **位置与外观**：高书柜右侧、比木椅略靠南（固定镜头偏左靠前）的深酒红绒面高背翼椅（逻辑层仍沿用“沙发”命名），宽靠背约到站立角色胸口；座位朝南偏中。
- **支持动词**：检查、躲藏。
- **交互细节**：
  - 躲藏：走到沙发背后按躲藏键 → 蹲伏，头部低于靠背，镜头几乎看不到玩家。松开/移动则站起。
  - 站在沙发背后但**不按躲藏** = 站立探头状态（这是一个合法的"半躲"姿态，专门用来触发 D03 的教训：找了掩体但没蹲下，照样被爆头）。
- **组合交互**：躲藏时若神秘人已进门，移动/起身会立刻暴露；坐垫可被检查（角色掀一下坐垫，无所获——纯留白交互）。
- **关联死法**：D03（沙发后未蹲被杀）。
- **Unity 要点**：躲藏点用 `HideSpot` 组件（定义蹲伏 anchor 与隐蔽判定盒）。
- **拓展钩子**：`HideSpot` 通用化后，任何家具后侧都可以配置成新躲藏点。

### 2. 被子
- **位置与外观**：揉成一团摊在床上的厚棉被，布料物理（简化版）。
- **支持动词**：检查、拾取、使用、投掷、躲藏、放置。
- **交互细节**：
  - 躲藏（在床上时）：钻进被子蜷缩，形成一个明显人形凸起——神秘人必定识破（D04 的演出核心：他盯着被子看一秒，然后对着凸起连开三枪）。
  - 拾取后可拖着走（单手拖拽态，地上留拖痕）。
  - 放置：拖到门口区域按放置 → 被子平铺在门内侧地面，进入"绊倒陷阱待命"状态（外观上就是一团被子，神秘人第一次会中招——但仅在配合关灯时，见 D21；亮灯时他会低头跨过去，这本身就是一条信息）。
  - 使用（铺好后靠近拉角）：玩家蹲在旁边抓住被角，神秘人踏上的瞬间猛拉 → 触发绊倒演出（唯一能让神秘人倒地的交互）。
- **组合交互**：被子 + 门口 + 黑暗 + 拉拽 = D21 全游戏最长演出的启动器；被子也可以盖到台灯上（灯光变暗、布料透光发红——纯氛围交互，也是"用布遮光"思路的回应）。
- **关联死法**：D04、D21。
- **Unity 要点**：不做真布料解算，用 6~8 骨骼的简化 cloth rig + 预制形态切换（团状/披挂/平铺/隆起）；"绊倒待命"是平铺形态上的触发器。
- **拓展钩子**：`TripTrap` 组件独立于被子，地毯复用同一组件（D16）。

### 3. 床
- **位置与外观**：北墙偏东的单人床，床头靠东墙、床侧朝向固定镜头；木质床架，床底有 40cm 空隙。
- **支持动词**：检查、躲藏。
- **交互细节**：床边按躲藏 → 钻入床底俯卧。镜头视角只能看到床沿，玩家确实"看不见自己"（借用黑暗恐惧感）。神秘人进门后径直走向床，蹲下、伸手拖出玩家处决（D11——他永远知道你在哪，藏是没用的，这是本作要反复传达的核心信息）。
- **组合交互**：床上的被子被拿走后，床面留下空印——微小的状态反馈。
- **关联死法**：D11。
- **Unity 要点**：床底躲藏是第二个 `HideSpot` 配置；拖出演出为配对动画。
- **拓展钩子**：床垫可掀（预留动词"使用"），未来可藏物品于床垫下。

### 4. 木椅（苏醒点）
- **位置与外观**：贴北墙正中、正对南墙 CRT（固定机位）的直背木椅，看着就"能抡"；座位朝南，参考构图里人物就坐在这里，是画面绝对中心。
- **支持动词**：检查、搬运、投掷、挥击（搬运态）、使用（放置顶门）。
- **交互细节**：
  - 苏醒：主角每次循环都以同一坐姿在此苏醒（复活点）。
  - 搬运：双手举起，移动速度减半。
  - 搬运态下对墙/窗/电视机按挥击 → 抡砸（砸墙三下出坑不穿 = D05；砸电视 = 结局入口之一）。
  - 投掷：掷向神秘人会被他侧身让过（所有投掷物皆如此——他不接、不挡，只闪）。
  - 使用（在关闭的房门前）：椅背卡到门把手下 → "顶门"状态。神秘人开门受阻约 3 秒，然后一脚踹开，椅子飞散（D09——门从来不是出路，但这 3 秒延迟本身是玩家可利用的机制余量，供组合流派使用）。
- **组合交互**：顶门 + 提前埋伏门后 = 可以偷袭到刚踹门、动作硬直中的神秘人（进入搏斗，结局仍败）；椅子可以搬到任何位置当垫脚/掩体（非正式掩体，挡不住子弹）。
- **关联死法**：D05、D09；所有循环的起点。
- **Unity 要点**：苏醒姿势为 Timeline 首帧固定 pose；`Carryable` 组件（双手 socket + 移动减速）；顶门状态是门上的 `Blockable` 插槽接收椅子。
- **拓展钩子**：`Blockable` 插槽同样接受抽屉柜（更重、拖延 5 秒），重物顶门可做成一个小策略族。

### 5. 书柜
- **位置与外观**：贴西墙北段的高书柜，五层，摆着书本，顶层斜靠着棒球棍。深色柜体在固定镜头左侧形成厚重边框。
- **支持动词**：检查、使用（推倒）。
- **交互细节**：
  - 站在侧面按使用（长按 2 秒发力）→ 整柜推倒。倒向门口方向可堵住半个门（D13：神秘人从门缝侧身探枪射击，不进屋也能杀你——再次传达"物理阻挡无意义"）。倒地的书柜成为新掩体（半高，可躲藏）。
  - 推倒时巨响 → 触发神秘人提前入场规则。
- **组合交互**：书柜内容物（棒球棍/书）先拿走再推倒，则倒地时无内容物散落（状态联动）。
- **关联死法**：D12（躲书柜侧面被发现）、D13（推倒堵门被门缝射杀）。
- **Unity 要点**：推倒 = 物理 Rigidbody 一次性施力 + 内容物同步脱离；倒地后再挂一个 `HideSpot`。
- **拓展钩子**：柜体层板预留 socket，可随内容更新摆放新物品，自动获得"可拿可扔"能力。

### 6. 棒球棍 ★核心道具
- **位置与外观**：书柜顶层，木质球棍，全房间最显眼的"武器语言"物品。
- **支持动词**：检查、拾取、投掷、挥击。
- **交互细节**：
  - 挥击（持棍）：横扫一记，可命中——神秘人（正面接近必被先枪杀 = D07；盲区偷袭可命中 = D08 开局）、顶灯/台灯（爆裂熄灭）、花瓶/挂钟/镜子（碎裂）、墙壁（留印）、窗户木板（碎一块，露出后面的砖墙——窗户是假出口）、**电视机（= 结局触发，E 段）**。
  - 挥击有 0.6 秒前摇，命中神秘人身体触发搏斗演出，命中头部（仅盲区偷袭角度可能）直接把他打踉跄。
- **组合交互**：棍 + 门后盲区 = D08；棍 + 打灯 + 躲藏 = D20；棍 + 电视机 = 结局。投掷棒球棍会被闪避且棍落地弹走（捡回浪费时间——暗示棍应该握着用）。
- **关联死法**：D07、D08、D18、D20、E 段。
- **Unity 要点**：挥击用近战 hitbox 扫描窗口（动画事件开关）；不同命中目标路由到目标自身的 `OnHit(HitInfo)`。
- **拓展钩子**：`MeleeWeapon` 组件通用化，未来任何可拾取物（台灯、书）都可配置为低配近战武器。

### 7. 房门 ★神秘人入口
- **位置与外观**：东墙偏北，朝房间北侧向内开的旧木门，无锁孔、无插销（检查时角色会摸门把手拧两下——锁不上，刻意的）。
- **支持动词**：检查、使用（开/关）、放置（接受顶门物）。
- **交互细节**：
  - 玩家可以开门——门外是一段**纯黑的走廊，走不进去**（迈步会被一种无形的迟滞顶回来，配低频嗡声。留白原则：不解释）。门是神秘人的入口，不是玩家的出口。
  - 关门/顶门只能拖延入场（顶门见木椅/抽屉柜条目）。
  - 门打开后门板遮住东北角，形成**门后盲区**（见布局图），玩家提前站进去，神秘人进门瞬间看不到你 → 唯一的先手机会（D08、D21 的空间基础）。
- **组合交互**：门 + 椅子/抽屉柜（顶门）；门内侧地面 + 被子/地毯（绊倒陷阱区）。
- **关联死法**：D08、D09、D13、D21（空间基础）。
- **Unity 要点**：门轴 HingeJoint 或动画驱动皆可，但需支持"被踹开"的爆发动画顶飞阻挡物；黑走廊用一个低照度小空间 + 移动迟滞体积。
- **拓展钩子**：走廊留白空间可在续作/更新中扩展为真实空间。

### 8. 顶灯
- **位置与外观**：天花板中央的吊灯，全屋主光源。
- **支持动词**：检查（仰头看）、挥击（跳劈/持长物可及）、（被投掷物命中）。
- **交互细节**：被棒球棍/投掷物命中 → 爆裂熄灭，全屋进入昏暗态（还有台灯时）或全黑态（台灯也灭时）。玻璃碎屑落地有音效。本循环内不可修复。
- **组合交互**：顶灯 + 台灯全灭 = 全黑 → 神秘人掏战术手电（D20 起）；黑暗是 D18–D21 整个"黑暗流派"的开关。
- **关联死法**：D18、D19、D20、D21。
- **Unity 要点**：`BreakableLight` 组件（HP=1，命中即碎）；碎后禁用 Light + 换损坏 mesh + 通知光照系统重估环境档位。
- **拓展钩子**：可扩展"打一半闪烁"状态（HP=2）制造恐怖节奏。

### 9. 台灯
- **位置与外观**：抽屉柜上的旧式台灯，暖黄光，副光源。
- **支持动词**：检查、拾取、使用（开/关）、投掷、挥击目标。
- **交互细节**：可开关（唯一玩家可控光源开关）；可拔起拿走（带着一小截扯断的电线，拿走即熄灭）；可投掷（碎裂）；可被打碎。**只关台灯不算破坏**，重开即亮——想制造持久黑暗必须"打碎"。
- **组合交互**：被子盖台灯 = 暗红氛围光；台灯 + 顶灯全灭 = 全黑。
- **关联死法**：D18（只打顶灯、台灯还亮，神秘人顺手开大台灯亮度——失败但给出"要全黑"的信息）。
- **Unity 要点**：复用 `BreakableLight` + 增加 `Switchable`。
- **拓展钩子**：`Switchable` 可复用到未来任何电器。

### 10. 墙壁
- **位置与外观**：四面墙，贴着起皮的旧壁纸。
- **支持动词**：检查、（承受挥击）。
- **交互细节**：被椅子/棒球棍砸击会留下真实的凹坑与墙皮剥落（持久到本循环结束），砸三下出一个明显的坑，但**永远砸不穿**（D05）。砸墙声很大 → 提前触发神秘人入场。每面墙的坑位独立记录。
- **组合交互**：无。它存在的意义就是让"逃跑流"死心，并用巨大声响惩罚鲁莽。
- **关联死法**：D05。
- **Unity 要点**：命中点贴 decal + 一次性碎屑粒子；坑数计数在 `ILoopResettable` 里回滚。
- **拓展钩子**：预留"某面墙敲上去声音不同"的空心音效开关（本作不用，留白备用）。

### 11. 电视机 ★结局本体
- **位置与外观**：南墙电视柜上的老式 CRT 电视，屏幕常亮雪花噪点，**它的位置就是游戏镜头的位置**。
- **支持动词**：检查、使用（配合遥控器）、挥击、（承受投掷/椅砸）。
- **交互细节**：
  - 玩家走近检查：角色低头凑近屏幕——此时游戏画面里角色的脸占满镜头（因为镜头就在屏幕处），玩家会看到角色似乎在"看着自己"。这是最强的结局引导演出。
  - 挥击/椅砸/投掷重物命中 → **触发结局 E 段**（详见流程脚本）：屏幕裂纹 Shader 出现在游戏画面本身上（裂的是"玩家的屏幕"），第二击后画面炸碎，切第一人称。
  - 循环数越高，雪花噪点越强、偶尔闪过一帧极暗的"房间反拍画面"（即从房间方向拍电视的画面——留白，不解释）。
- **组合交互**：遥控器换台（见下条）；镜子里能看到电视屏幕的反光。
- **关联死法**：E 段（唯一通关路径）。
- **Unity 要点**：屏幕裂纹是全屏后处理（裂在相机上，不是电视 mesh 上）——这是"镜头=电视"的技术表达核心；电视 mesh 本身也同步换损坏模型。
- **拓展钩子**：噪点画面是一张 RenderTexture 播放列表，后续可无成本塞入更多"闪帧"内容。

### 12. 遥控器
- **位置与外观**：抽屉柜上，老式电视遥控器。
- **支持动词**：检查、拾取、使用、投掷。
- **交互细节**：对着电视使用 → 换台。**无论换多少台都是同样的雪花**，但每按一下，雪花会极短暂地（3 帧）跳成"当前游戏画面本身"再跳回雪花——即电视上闪过你正看着的这个画面。这是"电视=镜头"最直接的引导道具。关机键无效（按了电视闪一下又自己亮起）。
- **组合交互**：无其他。它是纯引导物品。
- **关联死法**：无直接死法，服务结局引导。
- **Unity 要点**：闪帧 = 把主相机 RenderTexture 贴到电视屏幕 3 帧。
- **拓展钩子**：可增加特定循环数后按遥控器出现的特殊闪帧。

### 13. 神秘人主手枪（挂战术手电）
- **位置与外观**：神秘人右手的黑色半自动手枪，导轨挂一支战术手电（平时关闭）。
- **支持动词**：（玩家侧）搏斗中夺取 → 拾取、使用（射击）、投掷。
- **交互细节**：
  - 仅在搏斗演出的特定分支中被打飞落地（D21、D22），玩家可抢先捡起。
  - 玩家射击：弹仓仅剩 1 发，射击演出注定被闪避（D22），空枪扣扳机只有哒哒声。空枪可投掷（被闪避）。
  - 黑暗中神秘人会开启枪挂手电（光锥即死区，见光照系统）。
- **组合交互**：枪上的手电在搏斗中可能分离脱落（D21），成为独立的手电筒道具。
- **关联死法**：D20（手电反制）、D21、D22。
- **Unity 要点**：枪与手电是父子道具，演出关键帧可分离；玩家持枪射击为演出化射线。
- **拓展钩子**：弹数、卡壳等参数暴露在 ScriptableObject，便于调整"枪到底多没用"。

### 14. 备用手枪（风衣内）★注定失败的具象
- **位置与外观**：藏在神秘人风衣内侧枪套里的小型手枪，平时完全不可见。
- **支持动词**：无（玩家不可交互）。它只属于神秘人。
- **交互细节**：仅在"玩家已把神秘人逼入绝境"的分支（夺枪成功、手电照住他宣告胜利）中，被他从容掏出反杀（D21/D22 的收尾）。掏枪动作刻意缓慢——他从不慌张。
- **关联死法**：D21、D22。
- **Unity 要点**：演出道具，Timeline 激活即可。
- **拓展钩子**：风衣里"还有什么"永远不设上限——后续新增反制可以继续从风衣里掏（刀、第三把枪……），这是反制表的兜底叙事装置。

### 15. 战术手电筒（可分离）
- **位置与外观**：原挂在主手枪导轨上，搏斗中脱落后为独立圆柱手电，落地时亮着、光柱扫旋。
- **支持动词**：检查、拾取、使用（开/关/照射）、投掷。
- **交互细节**：黑暗拉扯（D21）中脱落后是地上唯一光源与视觉焦点。玩家捡起后可照明、可照射神秘人面部（他抬手挡光——全游戏他唯一的"防御姿态"，给玩家一瞬间的胜利感，然后备用枪反杀）。
- **组合交互**：手电 + 全黑房间 = 玩家版的光锥博弈（但照到他不致死，只硬直——不对称设计，武力差距的表达）。
- **关联死法**：D21。
- **Unity 要点**：独立 Spotlight 道具，落地滚动时光柱扫动为氛围重点（物理滚动 + 灯随动）。
- **拓展钩子**：可照射的目标响应接口 `IFlashlightReactive`，镜子（反光）与神秘人（挡光）都实现它。

### 16. 风衣（神秘人着装）
- **位置与外观**：神秘人的深色及膝风衣，行动时下摆摆动。
- **支持动词**：检查（仅在其倒地/搏斗特写时可见细节）。
- **交互细节**：搏斗特写与绊倒瞬间，镜头可瞥见风衣内侧的枪套轮廓——细心玩家能在被反杀**之前**就预见到备用枪的存在（试错沙盒的"观察即情报"原则）。
- **关联死法**：D21、D22 的伏笔。
- **Unity 要点**：布料用简化骨骼；内侧枪套是特写镜头专用高模细节。
- **拓展钩子**：同 14，风衣是"无限反制"的容器。

### 17. 抽屉柜
- **位置与外观**：贴西墙、高书柜南侧的三屉木柜，上面摆着台灯与遥控器；主镜头里常被书柜与扶手椅半遮，偏左侧家具组阴影里。
- **支持动词**：检查、使用（逐屉开关）、搬运（费力，速度 1/3）。
- **交互细节**：三个抽屉可分别拉开：一屉是缠乱的胶带与旧报纸（报纸上的字全部模糊不可读——留白），一屉是空的，一屉卡住要拉两次（拉开还是空的）。抽屉内容物可拿可扔，无功能——**刻意的无意义**，让搜刮型玩家也扑空，强化"答案不在物品里"的主题。
- **组合交互**：整柜可搬去顶门（比椅子多拖延 2 秒，见木椅条目的 `Blockable` 族）。
- **关联死法**：D09 变体（重物顶门）。
- **Unity 要点**：每屉独立 `Openable`；搬运复用 `Carryable`（重型参数）。
- **拓展钩子**：三个抽屉是天然的内容更新位。

### 18. 书本（若干）
- **位置与外观**：书柜上一排旧书，书脊字迹全部褪色不可读。
- **支持动词**：检查、拾取、投掷。
- **交互细节**：可逐本抽出、翻开（内页空白或字迹漫漶——留白）、投掷。掷向神秘人被侧身闪过（D10）；掷向灯可打灭；掷向电视机——第一本被弹开（屏幕晃一下出现一瞬裂纹后自愈！），这是结局的又一次强引导：**电视和别的东西不一样**。
- **组合交互**：多本书扔地上会改变神秘人走线（他绕开杂物——唯一的走位干扰手段，可配合陷阱流）。
- **关联死法**：D10；结局引导。
- **Unity 要点**：轻型 `Throwable`；电视"裂纹自愈"是一次性后处理脉冲。
- **拓展钩子**：书名/内页是最低成本的彩蛋位。

### 19. 花瓶
- **位置与外观**：床右侧（靠门一侧）小圆几上的白瓷花瓶，插着几支红玫瑰；位置显眼，也会自然引诱玩家在门口动线上制造碎片区。小圆几是不可搬运的场景底座，不作为独立交互物。
- **支持动词**：检查、拾取、投掷。
- **交互细节**：投掷必碎，碎裂声全屋最大 → 立即触发"神秘人提前入场"。掷向神秘人被闪避后砸墙碎裂（D10 变体）。碎片留地（本循环内持久），赤脚的主角踩过碎片区会跛脚减速 2 秒——鲁莽的代价。
- **组合交互**：碎片区也影响神秘人走线（绕行）。
- **关联死法**：D10 变体。
- **Unity 要点**：`Throwable` + 碎裂预制体替换 + 地面碎片触发区。
- **拓展钩子**：碎片区机制可复用到一切易碎物。

### 20. 窗户（木板封死）
- **位置与外观**：北墙偏西、木椅左侧上方的窗洞，被深色木框和数条木板封死；远看就是参考图里那幅阴沉挂画（超现实几何题材亦可），木板缝隙透不出任何光。近看才辨出是封窗。
- **支持动词**：检查、（承受挥击/投掷）。
- **交互细节**：棒球棍/椅子连砸可逐条敲碎木板（巨响、提前入场），全部敲碎后露出的是**一堵砌死的砖墙**（D15——"窗户"只是钉在砖墙上的一个装饰，此房间从物理上就没有外面）。砖墙继续砸 = 同墙壁规则，不穿。
- **组合交互**：无。与墙壁、房门共同构成"物理逃脱三连败"。
- **关联死法**：D15。
- **Unity 要点**：木板逐条 `Breakable`；砖墙复用墙壁 decal。
- **拓展钩子**：砖墙后同样预留空心音效开关（备用，本作不启用）。

### 21. 地毯
- **位置与外观**：从高背扶手椅前脚斜向延伸到门口的旧长条地毯。
- **支持动词**：检查、使用（抓角拉拽）。
- **交互细节**：蹲在远端抓角，神秘人踏上地毯瞬间猛拉 → 他一个趔趄**但不倒**（脚步一沉、单膝点地半秒即恢复，随即击杀 = D16）。与被子的区别：地毯太重太长，拉不动他——但这半秒趔趄让玩家看见"绊倒思路是对的，需要更轻更近的布"→ 指向被子（D21）。
- **组合交互**：地毯上再铺被子 = 无叠加效果（避免复杂度爆炸，被子判定优先）。
- **关联死法**：D16（并作为 D21 的思路桥梁）。
- **Unity 要点**：复用 `TripTrap`，结果枚举为"趔趄"而非"倒地"。
- **拓展钩子**：`TripTrap` 的结果分级（无效/趔趄/倒地）已天然支持新陷阱物。

### 22. 挂钟
- **位置与外观**：北墙偏东、床上方靠门一侧的圆挂钟，**永远停在同一时刻**（秒针在同一格抽搐、走不过去）。每次循环重置后依旧是这个时刻。
- **支持动词**：检查、拾取（摘下）、投掷。
- **交互细节**：检查时角色歪头看表——秒针抽搐声被放大（全屋唯一的"时间"意象，暗示循环，不解释）。可摘下投掷（被闪避/砸碎，碎后秒针声消失——房间反而更死寂）。
- **关联死法**：D10 变体（投掷物池）。
- **Unity 要点**：秒针抽搐是 0.5s 循环动画 + 空间音效。
- **拓展钩子**：特定循环数后秒针"多走一格"之类的微彩蛋位。

### 23. 镜子
- **位置与外观**：东墙半身镜，镜面有点旧但成像清楚。
- **支持动词**：检查、挥击、（手电照射）。
- **交互细节**：
  - 检查：角色站到镜前——玩家在游戏画面里同时看到角色背影与镜中正脸，而**镜子同时映出南墙的电视机**：玩家会在镜中看到"电视屏幕的雪花"与自己角色同框 → 第三个结局引导。
  - 手电照射镜面：反射光斑可晃到神秘人脸（他抬手挡 1 秒硬直 = D17 的"短暂有效"，随后照杀——但"致盲有用"的信息被确认，服务 D21 的手电对峙）。
  - 挥击可打碎（七年霉运音效彩蛋；碎镜后本循环内失去镜面引导）。
- **关联死法**：D17；结局引导。
- **Unity 要点**：镜面用第二相机 RenderTexture（低分辨率即可）或 URP 反射探针平面反射；反光晃眼为演出判定不做真光学。
- **拓展钩子**：镜中画面是"闪帧"类彩蛋的又一容器。
