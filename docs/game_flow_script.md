# 《困室》完整游戏流程脚本

> 本文定义演出意图与逐拍内容；发生实现规则冲突时，以 [gameplay_logic_spec.md](gameplay_logic_spec.md) 为准。

> 上游文档：[story_outline.md](story_outline.md)（原始构思 1–14 条 + 结局 x，本脚本全量覆盖并细化） · [game_outline.md](game_outline.md)（系统规则） · [items_interactions.md](items_interactions.md)（物品编号与交互定义）
>
> **阅读说明**
> - 死法编号 D01–D22。玩家可以以任意顺序触发（纯试错沙盒，无解锁门槛），本文的排列顺序只是**预期的典型玩家心路**，用于把控节奏与信息释放。
> - 每条死法包含：`触发条件`（玩家做了什么）→ `事件序列`（逐拍演出）→ `镜头与音效`（固定机位下的表现）→ `隐性信息`（这次死亡教会玩家什么——试错沙盒下唯一的进度语言）。
> - 神秘人全程零台词。所有时间以“苏醒后秒数”计：初始截止时间 45 秒；首次有效行为在 30 秒前发生则改为 30 秒；巨响取当前时间后 8 秒与既有截止时间中的更早值，规则细节见运行规范。
> - 参照边界：本脚本借用 MV 的观看关系、循环感和压迫氛围作为改编方向；D01–D22、时间窗、道具组合和 E1–E3 的具体节拍属于本作游戏设计，不宣称为 MV 已逐镜发生的事件。

## 第 0 段 · 开场（首次苏醒）

```
黑屏 2 秒 → 一声老式电视开机的"啵"声 → 画面亮起：
固定机位（=电视机位置）拍摄整个房间。轻微 CRT 扫描线。
主角以坐姿留在北墙正中的木椅上。约 4 秒后苏醒演出可自动结束，但没有有效操作时仍保持坐姿；第一次有效操作让主角起身并立即执行该操作（包括首次 E 交互）。
房间里唯一的声音：挂钟秒针在同一格上的抽搐声，嗒、嗒、嗒。
无任何文字。无任何提示。玩家开始自由行动。
达到入场截止时间后：门外一声脚步顿住的闷响（0.5 秒预警）→ 房门被推开，神秘人进入。若此前始终没有有效操作，主角仍坐在木椅上。
```

**设计意图**：首个循环里玩家几乎必死于 D01 或 D02——这是刻意的。第一次死亡与"无缝倒带"就是游戏规则的教学，比任何教程文字都快。

## 第 1 幕 · 蒙圈期（预期循环 1–3）

### D01 · 站着发懵被杀 ｜原文 1
- **触发条件**：神秘人进门时，玩家站在屋内开阔处，未持武器、未躲藏。
- **事件序列**：神秘人进门 → 目光锁定 → 快步走近至 3m → 抬枪 → 一枪命中胸口 → 主角向后跌倒 → **画面 1 帧硬切**：主角又坐在北墙木椅上，苏醒姿势。
- **镜头与音效**：枪声干脆无混响（房间小而闷）；死亡瞬间伴一声极短的电流"刺啦"。
- **隐性信息**：死亡不是结束，是重置。挂钟还停在同一格——时间没走。

### D02 · 坐着不动被杀 ｜原文 2
- **触发条件**：玩家全程无有效输入（或只转视角），仍坐/站在木椅起点区域。
- **事件序列**：因玩家全程静止，入场延迟至第 45 秒（房间死寂被拉长，秒针抽搐声越来越响）→ 神秘人进门，径直走到木椅正前方，站定，**低头看了主角一秒**（全脚本唯一一次"注视"）→ 抬枪爆头。
- **镜头与音效**：站定注视的一秒里，所有环境音消失，只剩主角呼吸。
- **隐性信息**：不动也是一种选择，他也回应了——不存在"躲过去"的消极解。以及：他似乎在观察你。

### D03 · 沙发后没蹲下 ｜原文 3
- **触发条件**：玩家位于沙发背后区域，但未按躲藏键（站立探头状态）。
- **事件序列**：神秘人进门 → 视线扫过沙发，主角头肩露在靠背上方 → 他略偏头（一个"就这？"的微动作）→ 抬枪一发命中头部。
- **镜头与音效**：固定机位恰好能同时拍到门口的他与沙发后的你——玩家眼睁睁看着自己"被看见"。
- **隐性信息**：掩体是真实机制（他确实先"看"了），但姿势不对等于没躲。→ 引导玩家发现躲藏键与蹲伏。

> **D03′ 变体·蹲了但起身**：玩家正确蹲伏，神秘人进门后视线扫过没发现，开始在屋内缓步搜索（全游戏唯一的"搜索"状态，约 8 秒）——若玩家保持不动 8 秒，他会走向沙发绕后查看（必然发现，处决）；若玩家中途起身或移动出声，立即转身击杀。**隐性信息**：躲藏能骗到他几秒，但这个房间小到无处可藏——藏不是答案，可"骗到几秒"这个机制留给了组合流派。

## 第 2 幕 · 求生本能期（预期循环 3–10）

### D04 · 被子里的人形 ｜原文 4
- **触发条件**：玩家钻进床上的被子躲藏。
- **事件序列**：神秘人进门 → 环视一圈没看到人 → 目光落在床上明显的人形凸起 → 走近，盯着被子静止 1.5 秒（凸起随主角呼吸微微起伏）→ 对着凸起连开 3 枪。
- **镜头与音效**：3 声枪响后被面渗开暗色；硬切。
- **隐性信息**：他不掀被子、不废话，直接射穿掩体——软掩体挡不住子弹。同时"他会先环视、目标不明时会走近查看"的感知规则再次确认。

### D05 · 椅子砸墙 ｜原文 5
- **触发条件**：玩家搬起木椅对任意墙面挥砸（≥1 下）。
- **事件序列**：第一砸墙皮剥落（巨响 → 触发提前入场：8 秒倒计时开始）→ 玩家最多砸出 3 下（一个明显的坑，但不穿）→ 神秘人破门，对还举着椅子的主角背影开枪。
- **镜头与音效**：砸墙声在小房间里震耳；神秘人的枪声在你的砸击节奏间隙里响起——被打断的劳动。
- **隐性信息**：①墙砸不穿；②巨响会把他更快引来——声音是有代价的资源。

### D06 · 投降 ｜原文 6
- **触发条件**：神秘人进门后，玩家面对他做出下跪动作（蹲键长按 = 跪地举手，靠近他且未持武器时自动识别为投降姿态）。
- **事件序列**：主角跪地、双手举过头顶 → 神秘人脚步**没有任何停顿**，走到面前 → 平举枪对准额头 → 停半秒 → 开枪。
- **镜头与音效**：那半秒里只有挂钟的抽搐声。
- **隐性信息**：不存在谈判、不存在慈悲。他不是来"抓"你的。（配合零台词，压抑感峰值之一。）

### D14 · 装死 ｜补充（原文 9"n 次类似循环"占位）
- **触发条件**：神秘人进门前玩家主动趴在地上不动（俯卧姿势）。
- **事件序列**：神秘人进门 → 看到地上的"尸体" → 走近，用鞋尖碰了碰主角肩膀 → 顿一秒 → 对后脑补一枪。
- **隐性信息**：他要的是确认死亡，不是看到死亡。骗术等级需要高于"演的"。

### D10 · 投掷攻击 ｜补充
- **触发条件**：玩家向神秘人投掷任意物品（书本/花瓶/挂钟/台灯/椅子/棒球棍）。
- **事件序列**：投掷物飞向神秘人 → 他侧身一让（永不伸手接、永不被砸中）→ 物品砸墙/落地（花瓶碎裂满地）→ 他在你捡下一件东西之前抬枪击杀。
- **隐性信息**：远程消耗不可行，他的反应快于你的投掷。但注意到：**他闪避时脚步会移动**——他不是钉在地上的，走位可以被"支配"（服务 D18 书本改道、陷阱流）。

### D11 · 床底 ｜补充
- **触发条件**：玩家钻入床底躲藏。
- **事件序列**：神秘人进门 → 不环视、不搜索，**径直走向床**（与 D03′ 的搜索行为形成刺骨对比）→ 单膝蹲下 → 一把拽住主角脚踝拖出 → 处决。
- **隐性信息**：某些藏身处他"根本不用找"。他对这个房间比你熟。（留白：为什么？不解释。）

### D12 · 书柜侧的死角 ｜补充
- **触发条件**：玩家贴在书柜侧面的镜头死角处（对电视机镜头而言不可见的位置）。
- **事件序列**：玩家从游戏画面里"消失"（镜头拍不到自己，只能靠声音确认位置——固定机位的独特体验）→ 神秘人进门，视线直接锁定书柜侧 → 玩家在画外被击杀，**只听见枪声**，硬切。
- **隐性信息**：镜头拍不到 ≠ 他看不到。**镜头的死角骗不过他，只骗得过"看电视的人"**——这是"镜头≠他的眼睛，镜头=另一个存在的眼睛"的第一次暗示，为结局蓄力。

### D09 · 顶门 ｜补充（原文 9 占位）
- **触发条件**：玩家用木椅（或抽屉柜）顶住房门。
- **事件序列**：第 30 秒门把手转动 → 顶住，门被推动数下不开（椅子腿在地板上滑出刺耳声）→ 静默 2 秒 → 一脚爆踹，椅子飞散，门撞墙 → 玩家若在门正面，被顺势一枪；若已利用这 3–5 秒躲好/就位，流程转入对应死法（D03′/D08 等）。
- **隐性信息**：顶门买得到 3–5 秒。**时间可以被制造**——这是组合流派最重要的资源发现。

### D13 · 推倒书柜堵门 ｜补充
- **触发条件**：玩家推倒书柜堵住门口。
- **事件序列**：书柜轰然倒下（巨响提前入场）→ 门被推开一条缝，被柜体卡住 → 神秘人不硬挤，从门缝**侧身探入持枪的手**，枪口随手电（若黑暗）或视线扫过房间 → 锁定玩家，隔着门缝射杀。
- **隐性信息**：他不需要进来也能杀你。物理阻挡的上限被彻底标定。（若玩家贴在门后盲区躲过了门缝扫射——他会收手、退后、撞开书柜进门，转 D08 判定：盲区依然被保留为唯一先手点。）

### D15 · 砸窗 ｜补充
- **触发条件**：玩家用棒球棍/椅子敲碎窗户木板。
- **事件序列**：木板逐条碎裂（每一下都是巨响）→ 最后一条木板落地，露出**一堵砌死的砖墙** → 主角愣住的 1 秒里，神秘人破门 → 背后一枪。
- **镜头与音效**：露出砖墙的瞬间配一个极低的嗡声——房间在告诉你它的本质。
- **隐性信息**：这个房间**从建造上就没有出口**。窗只是画在监狱墙上的窗。（配合 D05 墙、D09/D13 门，"物理逃脱三连败"闭环，玩家的思路被系统性地逼向别处。）

### D16 · 地毯拉拽 ｜补充
- **触发条件**：玩家蹲在地毯远端抓角，神秘人踏上地毯瞬间猛拉。
- **事件序列**：猛拉 → 神秘人一个趔趄、单膝点地半秒（全场第一次看到他失衡！）→ 但立即恢复，顺势抬枪击杀还抓着地毯角的主角。
- **隐性信息**：**他会失衡**。地毯太重拉不倒他——需要更轻、更近、更突然的东西。→ 直接指向被子（D21 的思路桥梁，原文 13 的前置教学）。

### D17 · 镜子反光 ｜补充
- **触发条件**：玩家（持手电，见 D21 前置；或利用台灯摆位）将光反射晃向神秘人面部。
- **事件序列**：光斑扫到脸 → 他抬手挡光，硬直约 1 秒（全场唯一"防御动作"）→ 玩家无论借机做什么（冲锋/逃向门口）都在硬直结束后被击杀。
- **隐性信息**：**致盲有用，能创造约 1 秒**。武力值差距无法弥补，但感官是可以攻击的。→ 服务黑暗流派与 D21 的手电对峙。

## 第 3 幕 · 武力对抗期（预期循环 8–15）

### D07 · 持棍迎战 ｜原文 7
- **触发条件**：玩家手持棒球棍，在神秘人视野内正面接近他。
- **事件序列**：玩家进入 5m → 神秘人不减速、不防备，抬枪 → 在挥击距离（1.5m）之外一枪命中 → 棒球棍脱手滚地。
- **镜头与音效**：棍子在地板上滚动的声音比枪声更长。
- **隐性信息**：近战武器的射程死于手枪射程——**正面永远够不到他**。必须让他"看不到"你的接近。

### D08 · 门后盲区偷袭 ｜原文 8 ★第一次"成功"
- **触发条件**：玩家持棒球棍提前站入门后盲区，神秘人进门瞬间挥击。
- **事件序列**：
  1. 神秘人进门，径直走向屋内（没看见你！全场玩家第一次心跳时刻）；
  2. 玩家挥棍命中其后脑/肩背 → 他踉跄扑倒半步，枪仍在手；
  3. 进入**搏斗演出**（对抗窗口 ×3，连打交互键）：主角骑压、抢夺持枪手腕、两人翻滚撞上抽屉柜（台灯坠地）；
  4. 无论对抗窗口输赢，最后一拍：神秘人膝顶脱身 → 拉开半米 → 贴身一枪。
- **镜头与音效**：搏斗全程固定机位远远看着，无特写——像监控录像里的一场无声扭打。
- **隐性信息**：**偷袭成立！盲区成立！他会被打疼！**——但徒手拉扯赢不了持枪的手。要么让枪离手，要么让他倒地。（原文 8 的完整实现；对抗窗口的"差一点"感是重试引擎。）

### D22 · 夺枪开火 ｜补充（原文 14"各种办法"收口）
- **触发条件**：D08 或 D21 中玩家主动拾起掉落的主枪；进入 D22 后玩家可在 `12s` 内开火。
- **事件序列**：玩家举枪 → 神秘人不躲不停，向你走来 → 第一次开火，唯一一发子弹被他侧肩闪过 → 再次扣扳机只播放空仓声；若玩家在 `12s` 内没有开火，则超时触发同一收尾 → 神秘人从风衣内侧掏出备用手枪，进入 `2s` 拔枪演出（前 `0.7s` 展露枪，后 `1.3s` 开火）→ 保留 `2s` 结算后击杀。
- **隐性信息**：**枪不是答案，枪从来就不是给你用的。**风衣里还有一把——武力对抗的天花板被焊死。玩家至此应彻底放弃"打赢他"，开始想"这一切到底是什么"。

## 第 4 幕 · 黑暗流派期（预期循环 12–20）｜原文 10–13

### D18 · 只打了顶灯 ｜原文 12 前置
- **触发条件**：玩家打碎顶灯，台灯仍接线但处于关闭，然后躲藏埋伏。
- **事件序列**：房间变暗（台灯关闭但仍接线，原本的暖黄光熄灭）→ 神秘人进门，扫一眼碎掉的顶灯 → 走到台灯前，**顺手把台灯重新打开** → 在恢复的光线里从容找到玩家，击杀。台灯断线、被持有或被子遮住时不触发此重亮动作。
- **隐性信息**：黑暗要做就做绝——**两个光源都得死**。他会修复你的布置（拧亮台灯是他全场唯一一次"整理房间"，微妙的恐怖）。

### D19 · 全黑乱撞 ｜原文 10–11（摸瞎经验教学）
- **触发条件**：玩家打碎全部光源，但无后续计划，在全黑中移动。
- **事件序列**：全黑（摸瞎经验 0 级 = 几乎纯黑画面，只有电视雪花的微光在南墙一角）→ 玩家磕碰家具的声音此起彼伏 → 神秘人进门，枪挂战术手电亮起——黑暗中一道锐利光锥（全游戏最佳画面之一）→ 光锥循声扫来 → 照到玩家 0.8 秒后枪响。
- **隐性信息**：①他有手电（原文 12 的信息提前给或此处给，取决于玩家路线）；②我在黑暗里活得越久，好像越能看清一点（**摸瞎经验开始累积**，跨循环保留）；③电视雪花是黑暗中唯一的光——镜头又一次把自己递到玩家眼前。

### D20 · 黑暗埋伏 vs 战术手电 ｜原文 12
- **触发条件**：全黑 + 玩家持棍在门后盲区或掩体后埋伏。
- **事件序列**：神秘人进门 → 手电亮起 → **他第一件事就是转身用光锥扫门后盲区**（他学不会被同一招打两次？不——他从一开始就都知道。留白）→ 光锥定住玩家 → 击杀。
- **隐性信息**：手电让黑暗埋伏失效——除非，让他在开灯之前就摔倒。绊倒 + 黑暗 + 盲区，三个已验证的机制指向同一个组合 → D21。

### D21 · 完美计划 ｜原文 13 ★主动选择的长演出
- **触发条件**：被子平铺门口内侧（绊倒陷阱待命）+ 全部光源已碎 + 玩家蹲在门后盲区，并在被角约 1.6m 内主动抓角；神秘人进入接触区后还需玩家提交拉拽。
- **事件序列**（逐拍）：
  1. 门开，神秘人踏入全黑的房间，手电尚未开启的半秒里踏上被子——玩家猛拉——**他重重摔倒**；倒地表现持续约 `1.2s`。
  2. 主手枪与战术手电脱手飞出，手电落地亮着、光柱扫旋，枪滑入黑暗；演出暂停，玩家保留正常移动与交互。主动拾取主枪直接进入 D22；第一次实际拾起手电则触发黑暗拉扯 QTE，连续三个 `1s` 对抗窗口。
  3. QTE 完成后手电脱手落地，玩家可再次手动拾取。再次拿起手电照镜进入 D17；照向神秘人则他挡光约 `3s`，再进入备用枪终结演出。D22 的备用枪拔枪演出为 `2s`（`0.7s` 展露枪、`1.3s` 开火），开火后保留 `2s` 结算并硬切木椅苏醒。
- **镜头与音效**：固定机位 + 一支乱扫的手电形成主要调度；暂停期间保留环境声与玩家操作反馈，不强制自动拿手电。手枪分支直接进入 D22，不要求先走手电分支。以上时间是本作游戏设计，不是 MV 时间码。
- **隐性信息**：**你已经用尽了这个房间里所有的"道理"，并且执行得完美无缺——依然输了。**问题从来不在计划里。玩家的目光（和绝望）终于只能落在那台从头到尾看着这一切的、屏幕还亮着的电视机上。

> **D21 后的全局变化**（唯一的脚本化状态推进，不违背沙盒原则——它不解锁任何交互，只改变演出）：完成 D21 后的每次苏醒，电视雪花噪点显著变强，偶尔闪过 1 帧"从房间方向拍摄电视机的反打画面"；遥控器换台的闪帧频率提高。所有引导火力集中到电视机上。

### E1 · 打碎电视机（第三人称最后一幕）
- **触发条件**：玩家对电视机执行挥击（棒球棍）或重物砸击（椅子/搬运物）。任意循环均可触发，无前置条件（沙盒原则——速通玩家第 2 个循环就砸也成立）。
- **事件序列**：
  1. **第一击**：裂纹出现——注意，裂纹是全屏后处理，**裂在玩家的屏幕上**，不是电视模型上。音效是玻璃闷响 + 电流啸叫。若神秘人在场，他此刻**第一次跑动**，冲向玩家——全场他唯一一次急迫；
  2. **第二击**（需在被拉开前完成；若被拉开则被击杀、正常循环，裂纹在下一循环开局仍残留一瞬再消失——告诉玩家"这个是有记录的，再来"）：画面轰然炸碎，白噪声炸响，黑屏 1.5 秒；
  3. 黑屏中，一声与开场相同的"啵"——
- **设计意图**：神秘人唯一一次跑动 = 系统性确认"你做对了"。此前他对你做任何事都从容不迫，唯独这件事让他急了。

### E2 · 第一人称·被拉入场景
- **事件序列**：
  1. 画面亮起——**第一人称观看者视角**。打碎电视后，原本在屏幕外观看的人被接管进房间；玩家先从屏幕前看到独立可见的原主角离开固定观看位置，然后可以自由环顾房间；
  2. 身后门响。玩家回头（此时玩家获得第一人称完整操控，可以在房间里走动数秒——同一个房间，从“里面”看，所有物品还在原位，但镜头感消失了，压迫感全变了）；
  3. 神秘人进门。第一人称下的他远比固定机位里高大；
  4. 玩家可以做任何事——拿棍、扔东西、躲避——一切照旧被反制（复用既有反制逻辑的第一人称版本，仅需 D01/D07/D10 三条的第一人称改编），最终被击杀。**这一次死亡没有硬切**——第一人称视野缓缓倒向地板，黑屏 3 秒。
- **设计意图**：打破电视 = 打破第三人称。把观看者拉入场景，原主角离开原观看位置；第一人称的死亡被刻意做“重”（无硬切、有倒地过程），与此前 22 种轻飘飘的死形成断裂感。

### E3 · 终局
- **事件序列**：
  1. 黑屏后画面直接亮起：**第一人称，坐在木椅上**（生产 `Bootstrap.EndingDirector` 使用 `CFG_EndingSequence`，并把玩家放到场景中的 `FUR_WoodChair` 现场位置；当前布局默认是北墙位置。身体无法起身，只能转头环顾——看得见旁边的沙发空着，看得见身后的电视机已经碎了，**碎了的电视机没有复原**：循环的规则第一次被打破了。`EndingSequenceDirector` 仅为非生产参考实现）；
  2. 房门打开。神秘人走入，走到面前，抬枪。枪口对准镜头（=你的脸）；
  3. 一秒的静止。挂钟的秒针，嗒、嗒、嗒——**然后走过了那一格**（全游戏唯一一次时间前进）；
  4. 枪响。黑屏。
  5. 静默 5 秒后，黑屏上极小的白字浮现游戏名，无制作名单滚动（名单收进主菜单）。游戏结束，无 New Game+，主菜单的"继续"变灰——**这个存档死了**。
- **设计意图**：留白到底。玩家打破了作为观看者的安全位置，于是轮到自己被"看"、被终结。不解释神秘人，不解释房间——秒针走过那一格，是给玩家的唯一一句"结束了"。
